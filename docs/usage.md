# Getting Started

The easiest way to play is to download the latest client from [2006Scape.org](https://2006Scape.org/).

For development you can build the server and client using Maven:

```bash
mvn -B clean install
```

Run `GameEngine` in `2006Scape Server` to start the server and `Client` in `2006Scape Client` to launch the client locally.
